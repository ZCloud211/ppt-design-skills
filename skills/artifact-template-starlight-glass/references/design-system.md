# 设计参数

参数来自保留的《星际拓荒》参考PPT。坐标使用1280 × 720像素画布；换尺寸时按比例缩放，不混用像素与磅。

## 画布与留白

| 项目 | 参考值 |
|---|---|
| 比例 | 16:9 |
| 画布 | 1280 × 720 px（13.333 × 7.5 in） |
| 左右内容边界 | x = 58—1222 |
| 顶部章节标签 | x 58 / y 36 / h 34 |
| 主标题 | x 58 / y 95 / w 1164 / h 76 |
| 标题强调线 | x 60 / y 180 / w 162 / h 5 |
| 内容起点 | y 216—218 |
| 内容通常结束 | y 634—645 |
| 小型来源注记 | x 58 / y约647 / h 24 |
| 底部主题名 | x 58 / y 680 |
| 页码 | x 1172 / y 675 / w 50 / h 29 |

来源较长或正文靠近底部时，应减少页脚元素或重新分配高度。标签、注记和页码不应成为阅读负担。

## 默认配色

| 用途 | 色值 |
|---|---|
| 背景渐变起点 | `#0C1522` |
| 背景渐变终点 | `#16283C` |
| 参考底色 | `#101C2C` |
| 正文米白 | `#F5F1E8` |
| 篝火橙 | `#F3AD70` |
| 浅金 | `#F4D5A1` |
| 次要文字 | `#B5C3CF` |
| 辅助蓝 | `#8FB7CF` |

背景使用约145°的低对比渐变。强调线从 `#EE9960` 渐变至 `#F6D7A8`。新主题保留深背景、浅正文和少量强调色的层次，避免只把所有对象染成同一种颜色。

## 渐变玻璃框

常见圆角半径24 px，边缘约1 px、`#D8D8D8`、24%不透明度。内部留白约24—28 px。

- 暖色框，约135°：`#B47548` 28% → `#CBAE8B` 16% → `#526F8F` 28%。
- 冷色框，约135°：`#698BA9` 25% → `#B2C7D3` 13% → `#BD956D` 18%。
- 百分数指不透明度。底框应让背景轻微透出，同时给正文提供稳定对比。
- 常规图片圆角约18—22 px；大图封面直达画布边缘。
- 无需为每段文字加框；连续事件与推荐理由可直接排在背景上。

## 字体与层级

参考中文为 `Hiragino Sans GB`，英文字母及数字主要使用 `Helvetica Neue`。在无该字体的设备上，选择已安装且含中文字符的无衬线字体，并重新渲染检查；不假定字体会自动嵌入PPTX。

| 元素 | 像素字号 | 约合磅值 |
|---|---:|---:|
| 封面中文标题 | 82 | 61.5 |
| 封面短副标题 | 28 | 21 |
| 内容主标题 | 46—49 | 34.5—36.75 |
| 分区小标题 | 27—30 | 20.25—22.5 |
| 正文 | 22—25 | 16.5—18.75 |
| 章节标签 | 20 | 15 |
| 参考资料说明 | 18—21 | 13.5—15.75 |
| 来源注记 | 14 | 10.5 |
| 页脚主题名 | 13 | 9.75 |

正文常规字重，标题加粗；段落行距参考1.18倍。表格中的范围是版式参考，不是要求把用户已有字体统一替换。来源注记可以小于正文，但重要结论和剧情解释应使用正文层级。

## 图片与封面

封面采用一张完整主题图，保留主体；文字区域可用轻微暗色渐变遮罩提高对比。若图片已有标题或标识，应避免重复堆叠或把新文字压在标识上。

参考中的游戏图属于案例内容。换题时先选择构图合适的新图，再决定图文比例；不要为迁就固定框裁掉关键信息。事实证据图的必要界面、文字和对象应可见。
